3.2.6. Interpretación espectral de la serie de Fourier

Desde un punto de vista espectral, la serie de Fourier proporciona una representación discreta del contenido en frecuencia de una señal periódica. Cada coeficiente ckc_kck​ está asociado a una componente armónica de frecuencia kω0k\omega_0kω0​, de modo que la periodicidad en el dominio temporal se traduce en una discretización del espectro en el dominio de la frecuencia. Como ejemplo, se muestra en la figura la serie de Fourier correspondiente a un tren de pulsos triangulares.

Esta interpretación permite analizar de forma cualitativa el comportamiento de las señales y los sistemas:

  • Señales cuyos coeficientes son significativos únicamente para valores pequeños de ∣k∣|k|∣k∣ presentan una variación lenta en el tiempo.

  • La presencia de armónicos de orden elevado se asocia a variaciones rápidas o a la existencia de discontinuidades.

Interpretación espectral: Suavidad / Abruptidad

En la siguiente gráfica interactiva se analiza la relación entre la forma de onda de la señal x~(t)\tilde{x}(t)x~(t) y el módulo de los coeficientes de su serie de Fourier, ∣ck∣|c_k|∣ck​∣, siendo:

x~(t)∝tanh⁡(s⋅(sin⁡(ω0t)+a)) \tilde{x}(t) \propto \tanh(s \cdot (\sin(\omega_0 t) + a))x~(t)∝tanh(s⋅(sin(ω0​t)+a))
(1)

Variando los parámetros se puede pasar de una señal puramente senoidal a una señal quasi-rectangular. Podemos variar la Abrupticidad (sss) y el Offset (aaa).

Observa:

  • Suavidad vs. Ancho de banda: Cuando la señal es suave (sss bajo), varía lentamente y su energía se concentra en frecuencias bajas. Al aumentar la abrupticidad (sss alto), las transiciones se vuelven rápidas, lo que obliga a que aparezcan armónicos de orden elevado para construir esos cambios bruscos.

  • Potencia media: Al hacer la señal más cuadrada (mayor sss), los coeficientes fundamentales crecen. Esto ocurre porque la señal “se ensancha” en el tiempo, aumentando su área y potencia media[1].

  • Simetría y armónicos pares: Si el offset es nulo (a=0a=0a=0), la señal tiene simetría de media onda[2] y sólo contiene armónicos impares. Al añadir asimetría (a≠0a \neq 0a=0), se rompe esta condición y aparecen los armónicos pares (k=±2,±4…k=\pm 2, \pm 4 \dotsk=±2,±4…).

  • Componente continua (c0c_0c0​): Este coeficiente representa el valor medio de la señal. Con a=0a=0a=0, la señal es simétrica respecto al eje horizontal y su media es nula. Al aumentar el offset, el valor medio deja de ser cero, haciendo que c0≠0c_0\neq0c0​=0.

VAL_STEEPNESS = 0.5  
VAL_OFFSET = 0.0     # Offset inicial (0 = simétrico)
N_POINTS = 400       
N_HARMONICS = 20     

COLOR_TIME = "blue" 
COLOR_FREQ = "blue" 

t_min, t_max = -2.5, 2.5
t_vals = np.linspace(t_min, t_max, N_POINTS)

# ==========================================
# 2. GENERACIÓN DE DATOS
# ==========================================

# A. Datos Tiempo
# x(t) = tanh( s * (sin(pi*t) + offset) )
def generate_signal(t_arr, s, off):
    if s < 1e-3: s = 1e-3
    # Normalizamos respecto al pico máximo posible para mantener la escala visual
    norm = np.tanh(s * (1.0 + abs(off)))
    return np.tanh(s * (np.sin(np.pi * t_arr) + off)) / norm

y_vals = generate_signal(t_vals, VAL_STEEPNESS, VAL_OFFSET)
source_time = ColumnDataSource(data=dict(t=t_vals, y=y_vals))

# B. Datos Frecuencia
k_vals = np.arange(-N_HARMONICS, N_HARMONICS + 1)
t_period = np.linspace(-1, 1, N_POINTS, endpoint=False) 

def calc_dft(s, off):
    if s < 1e-3: s = 1e-3
    norm = np.tanh(s * (1.0 + abs(off)))
    y_p = np.tanh(s * (np.sin(np.pi * t_period) + off)) / norm
    
    mags = []
    for k in k_vals:
        angle = k * np.pi * t_period
        re = np.mean(y_p * np.cos(angle))
        im = np.mean(y_p * (-np.sin(angle)))
        
        mag = np.sqrt(re**2 + im**2)
        if mag < 1e-4: mag = 0
        mags.append(mag)
        
    return np.array(mags)

mag_vals = calc_dft(VAL_STEEPNESS, VAL_OFFSET)
source_freq = ColumnDataSource(data=dict(k=k_vals, mag=mag_vals, zeros=np.zeros_like(k_vals)))

    const s = s_steep.value;
    const off = s_offset.value;
    const PI = Math.PI;
    
    // Normalización dinámica para que la señal no se salga de gráfica
    let norm = Math.tanh(s * (1.0 + Math.abs(off)));
    if (Math.abs(norm) < 1e-9) norm = 1.0;

    // --- 1. TIEMPO ---
    const t = source_t.data['t'];
    const y = source_t.data['y'];

    for (let i = 0; i < t.length; i++) {
        y[i] = Math.tanh(s * (Math.sin(PI * t[i]) + off)) / norm;
    }
    source_t.change.emit();

    // --- 2. FRECUENCIA (DFT) ---
    const N_integ = 200; 
    const k_arr = source_f.data['k'];
    const mag = source_f.data['mag'];
    
    let y_p = new Float32Array(N_integ);
    let t_p = new Float32Array(N_integ);
    
    // Generamos un periodo auxiliar
    for(let i=0; i<N_integ; i++){
        let ti = -1 + (2 * i / N_integ);
        t_p[i] = ti;
        y_p[i] = Math.tanh(s * (Math.sin(PI * ti) + off)) / norm;
    }
    
    for (let i = 0; i < k_arr.length; i++) {
        let k = k_arr[i];
        let sum_re = 0.0;
        let sum_im = 0.0;
        
        for (let j = 0; j < N_integ; j++) {
            let angle = PI * k * t_p[j]; 
            sum_re += y_p[j] * Math.cos(angle);
            sum_im += y_p[j] * (-Math.sin(angle));
        }
        
        let re = sum_re / N_integ;
        let im = sum_im / N_integ;
        let m = Math.sqrt(re*re + im*im);
        
        if (m < 1e-3) m = 0;
        mag[i] = m;
    }
    source_f.change.emit();
""")

s_offset.js_on_change('value', callback)

Regularidad de la señal y decaimiento espectral

Existe una relación matemática directa entre cómo de “suave” (regular) es una señal en el dominio temporal y la rapidez con la que decaen sus armónicos en el dominio frecuencial.

Como regla general, cada vez que una señal se “suaviza” (matemáticamente, cada vez que se integra), sus coeficientes espectrales se dividen por un factor proporcional a kkk (concretamente jkω0jk\omega_0jkω0​). Veremos la demostración formal de este fenómeno más adelante en la propiedad de integración (Table 1).

En la gráfica interactiva se puede visualizar este efecto. Prestar especial atención a la línea naranja discontinua, que representa exclusivamente el armónico fundamental (k=±1k=\pm 1k=±1) de la señal:

  • Onda Cuadrada (Discontinua): Los coeficientes decaen lentamente, del orden de O(1/k)\mathcal{O}(1/k)O(1/k). Como los armónicos superiores aún tienen mucho peso, la señal completa (azul) difiere notablemente de su armónico fundamental (naranja).

  • Onda Triangular (Continua): Al ser la integral de la onda cuadrada, sus coeficientes decaen más rápido, como O(1/k2)\mathcal{O}(1/k^2)O(1/k2). La señal completa ya empieza a suavizarse y a acercarse a la forma senoidal.

  • Splines de alto orden (Derivadas continuas): Al integrar sucesivamente, el decaimiento se vuelve drástico (O(1/k3)\mathcal{O}(1/k^3)O(1/k3), O(1/k4)…\mathcal{O}(1/k^4) \dotsO(1/k4)…). Esto provoca que los armónicos altos (k=3,5…k=3, 5 \dotsk=3,5…) se vuelvan diminutos y su aporte sea casi nulo. Como resultado, la señal original queda dominada por completo por el armónico fundamental, volviéndose visualmente indistinguible de una onda senoidal pura.

# 1. PARÁMETROS Y DATOS EXACTOS

COLOR_TIME = "blue"
COLOR_FUND = "orange"
COLOR_FREQ = "blue"
N_HARMONICS = 20

# Rango temporal de la gráfica
t_vals = np.linspace(-2.5, 2.5, 2000)
tau = np.mod(t_vals, 2) # Periodo T=2 para definir a trozos

# Vector de tiempo auxiliar de exactamente 1 periodo para la integración
t_1p = np.linspace(0, 2, 2000, endpoint=False)
tau_1p = np.mod(t_1p, 2)

# Armónicos centrados en cero
k_vals = np.arange(-N_HARMONICS, N_HARMONICS + 1)

# Función auxiliar para extraer el armónico fundamental en el tiempo
def get_fundamental(y_period):
    c_1 = np.mean(y_period * np.exp(-1j * np.pi * t_1p))
    return 2 * np.real(c_1 * np.exp(1j * np.pi * t_vals))

# Función auxiliar para extraer TODOS los coeficientes |c_k| reales
def get_all_ck(y_period):
    c_array = np.zeros_like(k_vals, dtype=float)
    for i, k in enumerate(k_vals):
        c = np.mean(y_period * np.exp(-1j * np.pi * k * t_1p))
        # Filtramos ruido numérico para armónicos nulos
        c_array[i] = np.abs(c) if np.abs(c) > 1e-4 else 0.0
    return c_array

# --- DOMINIO DEL TIEMPO ---
# Orden 1: Onda Cuadrada
y_1 = np.where(tau < 1, 1.0, -1.0)
y_1p = np.where(tau_1p < 1, 1.0, -1.0)
f_1 = get_fundamental(y_1p)
c_1 = get_all_ck(y_1p)

# Orden 2: Onda Triangular
y_2 = np.where(tau < 1, tau - 0.5, 1.5 - tau)
y_2 = y_2 / np.max(np.abs(y_2))
y_2p = np.where(tau_1p < 1, tau_1p - 0.5, 1.5 - tau_1p)
y_2p = y_2p / np.max(np.abs(y_2p))
f_2 = get_fundamental(y_2p)
c_2 = get_all_ck(y_2p)

# Orden 3: Spline Parabólico
y_3 = np.where(tau < 1, 0.5*tau**2 - 0.5*tau, -0.5*tau**2 + 1.5*tau - 1.0)
y_3 = y_3 / np.max(np.abs(y_3))
y_3p = np.where(tau_1p < 1, 0.5*tau_1p**2 - 0.5*tau_1p, -0.5*tau_1p**2 + 1.5*tau_1p - 1.0)
y_3p = y_3p / np.max(np.abs(y_3p))
f_3 = get_fundamental(y_3p)
c_3 = get_all_ck(y_3p)

# Orden 4 y 5: Splines Cúbico y Cuártico 
k_series = np.arange(1, 1000, 2)

y_4 = np.sum([(1.0/k**4) * np.cos(k * np.pi * t_vals) for k in k_series], axis=0)
y_4 = y_4 / np.max(np.abs(y_4))
y_4p = np.sum([(1.0/k**4) * np.cos(k * np.pi * t_1p) for k in k_series], axis=0)
y_4p = y_4p / np.max(np.abs(y_4p))
f_4 = get_fundamental(y_4p)
c_4 = get_all_ck(y_4p)

y_5 = np.sum([(1.0/k**5) * np.sin(k * np.pi * t_vals) for k in k_series], axis=0)
y_5 = y_5 / np.max(np.abs(y_5))
y_5p = np.sum([(1.0/k**5) * np.sin(k * np.pi * t_1p) for k in k_series], axis=0)
y_5p = y_5p / np.max(np.abs(y_5p))
f_5 = get_fundamental(y_5p)
c_5 = get_all_ck(y_5p)

all_data = {

    'ord2': {'y': y_2.tolist(), 'fund': f_2.tolist(), 'c': c_2.tolist()},
    'ord3': {'y': y_3.tolist(), 'fund': f_3.tolist(), 'c': c_3.tolist()},
    'ord4': {'y': y_4.tolist(), 'fund': f_4.tolist(), 'c': c_4.tolist()},
    'ord5': {'y': y_5.tolist(), 'fund': f_5.tolist(), 'c': c_5.tolist()}
}

# Inicializamos con la onda cuadrada
source_time = ColumnDataSource(data=dict(t=t_vals, y=y_1, fund=f_1))
source_freq = ColumnDataSource(data=dict(k=k_vals, c=c_1, zeros=np.zeros_like(k_vals)))

# ==========================================
# 2. GRÁFICOS

# --- TIEMPO ---
p_time = figure(width=600, height=300)
style_math_axes(p_time, x_range=(-2.5, 2.5), y_range=(-1.3, 1.8), xlabel="t", ylabel=r"$$\tilde{x}(t)$$")

Por otro lado, teniendo en cuenta que las exponenciales complejas son autofunciones de los sistemas LTI, el desarrollo en serie de Fourier a la salida de un sistema LTI:

Tendrá como coeficientes:

y~(t)⟶SFdk=H(kω0) ck \tilde{y}(t) \SF d_k = H(k\omega_0)\,c_ky~​(t)⟶SF​dk​=H(kω0​)ck​
(2)

donde H(kω0)H(k\omega_0)H(kω0​) es la respuesta en frecuencia del sistema a las frecuencias armónicas de la fundamental.

Asimismo, esta representación discreta del espectro constituye el punto de partida para establecer relaciones estructurales con otros conceptos del análisis de Fourier, como la transformada de Fourier de señales aperiódicas y la interpretación del muestreo como fenómeno dual de la periodicidad.
