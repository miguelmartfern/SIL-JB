Señales continuas y discretas

La información de una señal está contenida en un patrón de variaciones con una forma determinada.

Introducción¶

Ejemplo 1: señal de voz humana (variaciones de presión acústica).

Distintos patrones de variación producen distintos sonidos:

import sys
import os

from bokeh.plotting import figure, show, output_notebook

import numpy as np

from utils.plot_helpers import style_math_axes

output_notebook(verbose=False, hide_banner=True);

# ==== PARÁMETROS ====
sr = 16000  # frecuencia de muestreo
dur = 0.5   # segundos por letra
t_segment = np.linspace(0, dur, int(sr*dur), endpoint=False)

def envelope(t, attack=0.01, decay=0.25):
    env = np.ones_like(t)
    env *= np.minimum(1.0, t/attack)
    env *= np.exp(-t/decay)
    return env

# ==== SINTETIZAR LETRAS ====
# L
f0 = 120.0
harmonics = [1.0, 0.6, 0.3, 0.15]
sig_L = np.zeros_like(t_segment)
for i, a in enumerate(harmonics, start=1):
    sig_L += a * np.sin(2*np.pi*f0*i*t_segment)
sig_L *= envelope(t_segment, attack=0.02, decay=0.4)

# T
noise = np.random.normal(0, 1, size=t_segment.shape)
burst = np.zeros_like(t_segment)
burst_len = int(0.02*sr)
burst[:burst_len] = noise[:burst_len] * np.hanning(burst_len)
sig_T = burst * envelope(t_segment, attack=0.001, decay=0.1) + 0.02 * np.sin(2*np.pi*800*t_segment) * np.exp(-5*t_segment)

# I
f0_i = 160.0
formants = [2200, 3000]
sig_I = 0.6*np.sin(2*np.pi*f0_i*t_segment) * envelope(t_segment, attack=0.01, decay=0.5)
for fm in formants:
    sig_I += 0.3 * np.sin(2*np.pi*fm*t_segment) * envelope(t_segment, attack=0.01, decay=0.4)

# Normalizar
def norm(x): return x / (np.max(np.abs(x)) + 1e-9)
sig_L, sig_T, sig_I = map(norm, [sig_L, sig_T, sig_I])

# ==== CONCATENAR ====
gap = np.zeros(int(0.05*sr))
wave = np.concatenate([sig_L, gap, sig_T, gap, sig_I])
t_full = np.linspace(0, len(wave)/sr, len(wave), endpoint=False)

# ==== LÍMITES ====
start_L = 0
end_L = len(sig_L)
start_T = end_L + len(gap)
end_T = start_T + len(sig_T)
start_I = end_T + len(gap)
end_I = start_I + len(sig_I)

# ==== FUENTES DE DATOS ====
src_L = ColumnDataSource(data=dict(time=t_full[start_L:end_L], amp=sig_L, letter=["L"]*len(sig_L)))
src_T = ColumnDataSource(data=dict(time=t_full[start_T:end_T], amp=sig_T, letter=["T"]*len(sig_T)))
src_I = ColumnDataSource(data=dict(time=t_full[start_I:end_I], amp=sig_I, letter=["I"]*len(sig_I)))

# ==== GRAFICAR ====
TOOLS = "pan,wheel_zoom,box_zoom,reset,save,hover"
p = figure(title="Onda de audio: Pronunciación sintetizada de las letras L, T e I", 
            sizing_mode="stretch_width",
            max_width=600,
            height=400, 
            tools=TOOLS)

# Líneas por letra
p.line('time', 'amp', source=src_L, color="blue", line_width=2)
p.line('time', 'amp', source=src_T, color="green", line_width=2)
p.line('time', 'amp', source=src_I, color="red", line_width=2)

# Líneas divisorias
v1 = Span(location=end_L/sr, dimension='height', line_dash='dashed', line_width=1, line_color="gray")
v2 = Span(location=end_T/sr, dimension='height', line_dash='dashed', line_width=1, line_color="gray")
p.add_layout(v1)
p.add_layout(v2)

# Etiquetas ejes
p.xaxis.axis_label = "Tiempo (s)"
p.yaxis.axis_label = "Amplitud"
p.toolbar.logo = None

style_math_axes(
    p,
    x_range=(0, len(wave)/sr),
    y_range=(-1, 1),
    xlabel="Tiempo (s)",
    ylabel="Amplitud"
)

hover = HoverTool(
    tooltips=[
        ("Letra", "@letter"),
        ("Tiempo (s)", "@time{0.000}"),
        ("Amplitud", "@amp{0.000}")
    ],
    mode="vline"  # muestra valores verticalmente alineados
)
p.add_tools(hover)

# ==== CAPTION (debajo) ====

#                    text_font_size="10pt", text_color="gray"), 'below')

# ==== MOSTRAR ====
show(p)

Representación matemática: funciones de una o más variables independientes.

Aquí sólo nos ocuparemos de señales con una variable independiente.

En general, consideramos que es el tiempo: x(t)x(t)x(t) (aunque no tiene por qué).

Vamos a considerar dos tipos básicos de señales:

  • Continuas: la variable independiente es continua ⇒\Rightarrow⇒ se definen para una sucesión continua de valores de la variable independiente.

    Notación: x(t)\boxed{x(t)}x(t)​, con t∈ℜt\in\realt∈ℜ.

    Ejemplos: señal de voz con el tiempo, presión atmosférica con altitud.

  • Discretas: la variable independiente sólo toma un conjunto discreto de valores. También se las llama secuencia discreta.

    Notación: x[n]\boxed{x[n]}x[n]​, con n∈Zn\in\Zn∈Z.

    Ejemplos: valor del IBEX-35 al final de cada sesión, muestreo de señales continuas (muestras equiespaciadas).

Se mostrarán las señales continuas y discretas de forma paralela, para irlas relacionando. En el capítulo de muestreo (7), veremos cómo se puede pasar de unas a otras, idealmente sin error.

Clases de señales¶

Veremos a continuación distintos tipos de señales que tendrán importancia a lo largo de toda la asignatura.

Real e imaginaria: simetría respecto a la conjugación.

  • Real pura: simétrica respecto a la conjugación.

    x∗(t)=x(t),x^*(t)=x(t),x∗(t)=x(t),
    (1)
    x∗[n]=x[n].x^*[n]=x[n].x∗[n]=x[n].
    (2)

  • Imaginaria pura: antisimétrica respecto a la conjugación.

    x∗(t)=−x(t),x^*(t)=-x(t),x∗(t)=−x(t),
    (3)
    x∗[n]=−x[n].x^*[n]=-x[n].x∗[n]=−x[n].
    (4)
Par e impar: simetría respecto a la inversión en el tiempo. Se aplica a señales reales.

  • Par: simétrica respecto al eje de ordenadas.

    x(−t)=x(t),x(-t)=x(t),x(−t)=x(t),
    (5)
    x[−n]=x[n].x[-n]=x[n].x[−n]=x[n].
    (6)

  • Impar: antisimétrica respecto al eje de ordenadas.

    x(−t)=−x(t),x(-t)=-x(t),x(−t)=−x(t),
    (7)
    x[−n]=−x[n].x[-n]=-x[n].x[−n]=−x[n].
    (8)

    En el origen, como x(0)=−x(0)x(0)=-x(0)x(0)=−x(0), se cumple:

    x(0)=0,x(0)=0,x(0)=0,
    (9)
    x[0]=0,x[0]=0,x[0]=0,
    (10)
Hermítica y antihermítica: Equivalente para señales complejas.

  • Hermítica: simétrica respecto al eje de ordenadas y la conjugación.

    x∗(−t)=x(t),x^*(-t)=x(t),x∗(−t)=x(t),
    (11)
    x∗[−n]=x[n].x^*[-n]=x[n].x∗[−n]=x[n].
    (12)

  • Antihermítica: antisimétrica respecto al eje de ordenadas y la conjugación.

    x∗(−t)=−x(t),x^*(-t)=-x(t),x∗(−t)=−x(t),
    (13)
    x∗[−n]=−x[n].x^*[-n]=-x[n].x∗[−n]=−x[n].
    (14)

Toda señal se puede poner como suma de sus partes real e imaginaria, par e impar, hermítica y antihermítica:

x(t)=xr(t)+xi(t)=ℜ{x(t)}+ℑ{x(t)}.x(t)=x_r(t)+x_i(t)=\Re\{x(t)\}+\Im\{x(t)\}.x(t)=xr​(t)+xi​(t)=ℜ{x(t)}+ℑ{x(t)}.
(15)
x(t)=xe(t)+xo(t)=Ev{x(t)}+Od{x(t)},x(t)∈ℜ.x(t)=x_e(t)+x_o(t)=\mathcal{Ev}\{x(t)\}+\mathcal{Od}\{x(t)\},\quad x(t)\in\real.x(t)=xe​(t)+xo​(t)=Ev{x(t)}+Od{x(t)},x(t)∈ℜ.
(16)
x(t)=xh(t)+xa(t).x(t)=x_h(t)+x_a(t).x(t)=xh​(t)+xa​(t).
(17)

Las expresiones para el caso discreto son equivalentes.

{x(t)=xe(t)+xo(t),x(−t)=xe(−t)+xo(−t)=xe(t)−xo(t)\begin{cases}x(t)=x_e(t)+x_o(t),\\x(-t)=x_e(-t)+x_o(-t)=x_e(t)-x_o(t)\end{cases}{x(t)=xe​(t)+xo​(t),x(−t)=xe​(−t)+xo​(−t)=xe​(t)−xo​(t)​

A continuación veremos otros tipos de señales: periódicas, de energía y de potencia.

Señales periódicas¶

Dada su importancia las vemos aparte.

Definición de Señal periódica continua

Una señal continua, x(t)x(t)x(t), es periódica si:

∃ T∈ℜ+/x(t)=x(t+T),∀t∈ℜ.\exists\ T\in\real^+ /\quad \boxed{x(t)=x(t+T)},\quad \forall t\in\real.∃ T∈ℜ+/x(t)=x(t+T)​,∀t∈ℜ.
(24)

TTT: periodo de la señal.

Ejemplos:

Si x(t)x(t)x(t) es periódica con periodo TTT, también lo es con periodo mT, m∈NmT,\ m\in\NmT, m∈N.

T0T_0T0​: periodo fundamental de la señal. Valor más pequeño de TTT para el que se satisface:

x(t)=x(t+T0).x(t)=x(t+T_0).x(t)=x(t+T0​).
(25)
Nota

Si x(t)x(t)x(t) es constante, no está definido T0T_0T0​, ya que es periódica para cualquier TTT.

Definición de Señal aperiódica continua

Una señal que no es periódica.

Ejemplos:

import numpy as np

from bokeh.plotting import figure, show, output_notebook
from bokeh.models import ColumnDataSource, CustomJS, Select, Div, Slider
from bokeh.layouts import column, row

from utils.plot_helpers import style_math_axes

output_notebook(verbose=False, hide_banner=True);

# ==============================================================================
# 1. EJE TEMPORAL
# ==============================================================================

t_min, t_max = -4.0, 4.0
num_points = 2000
t = np.linspace(t_min, t_max, num_points)

initial = "Coseno"
A0 = 1.0
T0 = 1.0

x0 = A0 * np.cos(2*np.pi*t/T0)
x_shift0 = A0 * np.cos(2*np.pi*(t + T0)/T0)

source = ColumnDataSource(data=dict(
    t=t,
    x=x0,
    x_shift=x_shift0,
))

# ==============================================================================
# 2. FIGURA
# ==============================================================================

p = figure(
    height=400,
    width=650,
    title="Señal periódica: comparación entre x(t) y x(t+T)",
    tools="pan,wheel_zoom,reset"
)

p.line("t", "x", source=source, line_width=3, color="blue",
       legend_label="x(t)")

p.line("t", "x_shift", source=source, line_width=2, color="red",
       line_dash="dashed", alpha=0.65, legend_label="x(t+T)")

p.line(t, np.zeros_like(t), color="black", alpha=0.4)

p.grid.grid_line_alpha = 0.25
p.legend.location = "top_right"
p.legend.click_policy = "hide"

style_math_axes(
    p,
    x_range=(t_min, t_max),
    y_range=(-2.5, 2.5),
    xlabel="t",
    ylabel="amplitud"
)

# ==============================================================================
# 3. CONTROLES Y TEXTO
# ==============================================================================

select = Select(
    title="Tipo de señal",
    value=initial,
    options=["Coseno", "Seno", "Suma de armónicos", "Cuadrada", "No periódica"],
    width=220
)

amp_slider = Slider(
    title="Amplitud A",
    start=0.2,
    end=2.0,
    value=A0,
    step=0.1,
    width=220
)

period_slider = Slider(
    title="Periodo T",
    start=0.5,
    end=3.0,
    value=T0,
    step=0.1,
    width=220
)

info = Div(width=650)

texts = {
    "Coseno": """
    <b>Señal periódica: coseno</b><br>
    La señal cumple:<br>
    <span style="font-size:18px;">x(t) = x(t+T)</span><br><br>
    Puedes cambiar su amplitud A y su periodo T.
    """,

    "Seno": """
    <b>Señal periódica: seno</b><br>
    La señal cumple:<br>
    <span style="font-size:18px;">x(t) = x(t+T)</span><br><br>
    Al aumentar T, la señal oscila más lentamente.
    """,

    "Suma de armónicos": """
    <b>Señal periódica no sinusoidal</b><br>
    Aunque no es un seno puro, sigue siendo periódica:<br>
    <span style="font-size:18px;">x(t) = x(t+T)</span><br><br>
    Está formada por la suma de varios armónicos.
    """,

    "Cuadrada": """
    <b>Señal cuadrada periódica</b><br>
    La señal toma valores constantes por tramos, pero se repite cada periodo:<br>
    <span style="font-size:18px;">x(t) = x(t+T)</span>
    """,

    "No periódica": """
    <b>Señal no periódica</b><br>
    En este caso, al desplazar la señal un tiempo T, no coincide consigo misma:<br>
    <span style="font-size:18px;">x(t) ≠ x(t+T)</span><br><br>
    La envolvente exponencial rompe la periodicidad.
    """
}

info.text = texts[initial]

callback = CustomJS(
    args=dict(
        source=source,
        select=select,
        amp_slider=amp_slider,
        period_slider=period_slider,
        texts=texts,
        info=info
    ),
    code="""
    const data = source.data;
    const t = data["t"];

    const name = select.value;
    const A = amp_slider.value;
    const T = period_slider.value;

    const x = [];
    const x_shift = [];

    for (let i = 0; i < t.length; i++) {
        const ti = t[i];

        let value;
        let value_shift;

        if (name === "Coseno") {
            value = A * Math.cos(2*Math.PI*ti/T);
            value_shift = A * Math.cos(2*Math.PI*(ti + T)/T);
        }

        else if (name === "Seno") {
            value = A * Math.sin(2*Math.PI*ti/T);
            value_shift = A * Math.sin(2*Math.PI*(ti + T)/T);
        }

        else if (name === "Suma de armónicos") {
            value = A * (
                Math.cos(2*Math.PI*ti/T)
                + 0.4*Math.cos(4*Math.PI*ti/T)
            );

            value_shift = A * (
                Math.cos(2*Math.PI*(ti + T)/T)
                + 0.4*Math.cos(4*Math.PI*(ti + T)/T)
            );
        }

        else if (name === "Cuadrada") {
            value = A * Math.sign(Math.sin(2*Math.PI*ti/T));
            value_shift = A * Math.sign(Math.sin(2*Math.PI*(ti + T)/T));
        }

        else if (name === "No periódica") {
            value = A * Math.exp(-0.4*ti*ti) * Math.cos(2*Math.PI*ti/T);

            value_shift = A * Math.exp(-0.4*(ti + T)*(ti + T))
                        * Math.cos(2*Math.PI*(ti + T)/T);
        }

        x.push(value);
        x_shift.push(value_shift);
    }

    data["x"] = x;
    data["x_shift"] = x_shift;

    info.text = texts[name];

    source.change.emit();
    """
)

select.js_on_change("value", callback)
amp_slider.js_on_change("value", callback)
period_slider.js_on_change("value", callback)

layout = column(
    p,
    row(select, amp_slider, period_slider),
    info
)

show(layout)

Definición de Señal periódica discreta

Una señal discreta, x[n]x[n]x[n], es periódica si:

∃ N∈N/x[n]=x[n+N],∀n∈Z.\exists\ N\in\N /\quad \boxed{x[n]=x[n+N]},\quad \forall n\in\Z.∃ N∈N/x[n]=x[n+N]​,∀n∈Z.
(28)

NNN: periodo de la señal.

Ejemplos:

Si x[n]x[n]x[n] es periódica con periodo NNN, también lo es con periodo mN, m∈NmN,\ m\in\NmN, m∈N.

N0N_0N0​: periodo fundamental de la secuencia discreta. Valor más pequeño de NNN para el que se satisface:

x[n]=x[n+N0].x[n]=x[n+N_0].x[n]=x[n+N0​].
(29)

Si x[n]x[n]x[n] es constante, N0=1N_0=1N0​=1, que es el periodo mínimo que puede tener una señal discreta.
