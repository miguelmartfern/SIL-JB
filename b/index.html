Parámetros de interés de las señales

Vemos algunos parámetros de interés de las señales, tanto continuas como discretas.

Valor medio¶

Valor medio en un intervalo¶

El valor medio de una señal representa el promedio de sus valores dentro de un intervalo dado.

Señales continuas

Para una señal continua x(t)x(t)x(t) definida en el intervalo t1≤t≤t2t_1 \le t \le t_2t1​≤t≤t2​:

xˉ=Δ1t2−t1∫t1t2x(t) dt\bar{x} \overset{\Delta}{=} \frac{1}{t_2-t_1} \int_{t_1}^{t_2} x(t)\,dtxˉ=Δt2​−t1​1​∫t1​t2​​x(t)dt
(1)

Si el intervalo es simétrico respecto al origen, −T≤t≤T-T \le t \le T−T≤t≤T:

xˉ=Δ12T∫−TTx(t) dt\bar{x} \overset{\Delta}{=} \frac{1}{2T} \int_{-T}^{T} x(t)\,dtxˉ=Δ2T1​∫−TT​x(t)dt
(2)
Señales discretas

Para una señal discreta x[n]x[n]x[n] definida en el intervalo n1≤n≤n2n_1 \le n \le n_2n1​≤n≤n2​:

xˉ=Δ1n2−n1+1∑n=n1n2x[n]\bar{x} \overset{\Delta}{=} \frac{1}{n_2-n_1+1} \sum_{n=n_1}^{n_2} x[n]xˉ=Δn2​−n1​+11​n=n1​∑n2​​x[n]
(3)

Si el intervalo es simétrico respecto al origen, −N≤n≤N-N \le n \le N−N≤n≤N:

xˉ=Δ12N+1∑n=−NNx[n]\bar{x} \overset{\Delta}{=} \frac{1}{2N+1} \sum_{n=-N}^{N} x[n]xˉ=Δ2N+11​n=−N∑N​x[n]
(4)

Valor medio total¶

El valor medio total, o simplemente valor medio, describe el promedio de una señal cuando se considera todo su dominio.

Señales continuas

Para una señal continua x(t)x(t)x(t):

xAV=Δlim⁡T→∞1T∫−T/2T/2x(t) dtx_\text{AV} \overset{\Delta}{=} \lim_{T\to\infty} \frac{1}{T} \int_{-T/2}^{T/2} x(t)\,dtxAV​=ΔT→∞lim​T1​∫−T/2T/2​x(t)dt
(5)

De forma equivalente:

xAV=Δlim⁡T→∞12T∫−TTx(t) dtx_\text{AV} \overset{\Delta}{=} \lim_{T\to\infty} \frac{1}{2T} \int_{-T}^{T} x(t)\,dtxAV​=ΔT→∞lim​2T1​∫−TT​x(t)dt
(6)
Señales discretas

Para una señal discreta x[n]x[n]x[n]:

xAV=Δlim⁡N→∞12N+1∑n=−NNx[n]x_\text{AV} \overset{\Delta}{=} \lim_{N\to\infty} \frac{1}{2N+1} \sum_{n=-N}^{N} x[n]xAV​=ΔN→∞lim​2N+11​n=−N∑N​x[n]
(7)

Valor medio para señales periódicas¶

Si la señal es periódica, su valor medio puede calcularse sobre un único periodo.

Señales continuas

Para una señal continua periódica de periodo TTT:

xAV=Δ1T∫⟨T⟩x(t) dtx_\text{AV} \overset{\Delta}{=} \frac{1}{T} \int_{\langle T\rangle} x(t)\,dtxAV​=ΔT1​∫⟨T⟩​x(t)dt
(8)
Señales discretas

Para una señal discreta periódica de periodo NNN:

xAV=Δ1N∑n∈⟨N⟩x[n]x_\text{AV} \overset{\Delta}{=} \frac{1}{N} \sum_{n\in\langle N\rangle} x[n]xAV​=ΔN1​n∈⟨N⟩∑​x[n]
(9)

Valor de pico¶

El valor de pico mide el valor máximo que alcanza el módulo de una señal.

Señales continuas
xp=Δmax⁡{∣x(t)∣, t∈R}x_p \overset{\Delta}{=} \max\{|x(t)|,\ t\in\mathbb{R}\}xp​=Δmax{∣x(t)∣, t∈R}
(10)
Señales discretas
xp=Δmax⁡{∣x[n]∣, n∈Z}x_p \overset{\Delta}{=} \max\{|x[n]|,\ n\in\mathbb{Z}\}xp​=Δmax{∣x[n]∣, n∈Z}
(11)

Potencia instantánea¶

Por analogía con señales que representan magnitudes físicas, se puede hablar de potencia y energía asociadas a una señal.

Por ejemplo, para una resistencia, la potencia instantánea es:

p(t)=v(t)i(t)=1Rv2(t)=Ri2(t)p(t)=v(t)i(t)=\frac{1}{R}v^2(t)=Ri^2(t)p(t)=v(t)i(t)=R1​v2(t)=Ri2(t)
(12)

Por tanto, la potencia es proporcional al cuadrado de la señal. De forma general:

Señales continuas
Pi(t)=Δ∣x(t)∣2P_i(t) \overset{\Delta}{=} |x(t)|^2Pi​(t)=Δ∣x(t)∣2
(13)
Señales discretas
Pi[n]=Δ∣x[n]∣2P_i[n] \overset{\Delta}{=} |x[n]|^2Pi​[n]=Δ∣x[n]∣2
(14)

Energía¶

Energía

La energía de una señal se define como la suma, o integral, de su potencia instantánea.

Energía en un intervalo de tiempo¶

Señales continuas

En el intervalo t1≤t≤t2t_1\le t\le t_2t1​≤t≤t2​:

E=Δ∫t1t2∣x(t)∣2 dtE \overset{\Delta}{=} \int_{t_1}^{t_2} |x(t)|^2\,dtE=Δ∫t1​t2​​∣x(t)∣2dt
(15)

Para un intervalo simétrico, −T≤t≤T-T\le t\le T−T≤t≤T:

ET=Δ∫−TT∣x(t)∣2 dtE_T \overset{\Delta}{=} \int_{-T}^{T} |x(t)|^2\,dtET​=Δ∫−TT​∣x(t)∣2dt
(16)
Señales discretas

En el intervalo n1≤n≤n2n_1\le n\le n_2n1​≤n≤n2​:

E=Δ∑n=n1n2∣x[n]∣2E \overset{\Delta}{=} \sum_{n=n_1}^{n_2} |x[n]|^2E=Δn=n1​∑n2​​∣x[n]∣2
(17)

Para un intervalo simétrico, −N≤n≤N-N\le n\le N−N≤n≤N:

EN=Δ∑n=−NN∣x[n]∣2E_N \overset{\Delta}{=} \sum_{n=-N}^{N} |x[n]|^2EN​=Δn=−N∑N​∣x[n]∣2
(18)

Energía total¶

La energía total corresponde a la energía de la señal en un intervalo infinito.

Señales continuas
E∞=Δlim⁡T→∞∫−TT∣x(t)∣2 dt=∫−∞∞∣x(t)∣2 dtE_\infty \overset{\Delta}{=} \lim_{T\to\infty} \int_{-T}^{T} |x(t)|^2\,dt = \int_{-\infty}^{\infty} |x(t)|^2\,dtE∞​=ΔT→∞lim​∫−TT​∣x(t)∣2dt=∫−∞∞​∣x(t)∣2dt
(19)
Señales discretas
E∞=Δlim⁡N→∞∑n=−NN∣x[n]∣2=∑n=−∞∞∣x[n]∣2E_\infty \overset{\Delta}{=} \lim_{N\to\infty} \sum_{n=-N}^{N} |x[n]|^2 = \sum_{n=-\infty}^{\infty} |x[n]|^2E∞​=ΔN→∞lim​n=−N∑N​∣x[n]∣2=n=−∞∑∞​∣x[n]∣2
(20)
Atención

Hay señales para las que esta integral o sumatorio no converge. Por ejemplo:

x1(t)=1t,x2(t)=Cx_1(t)=\frac{1}{\sqrt{t}},\qquad x_2(t)=Cx1​(t)=t​1​,x2​(t)=C
(21)
x1[n]=1n,x2[n]=Cx_1[n]=\frac{1}{\sqrt{n}},\qquad x_2[n]=Cx1​[n]=n​1​,x2​[n]=C
(22)

En estos casos, E∞=∞E_\infty=\inftyE∞​=∞. Por ello, nos interesa introducir otra medida relacionada: la potencia media.

Potencia media¶

Potencia media

La potencia media es el valor medio de la potencia instantánea.

En general, la potencia media viene dada por:

Señales continuas
P∞=Δlim⁡T→∞1T∫−T/2T/2∣x(t)∣2 dtP_\infty \overset{\Delta}{=} \lim_{T\to\infty} \frac{1}{T} \int_{-T/2}^{T/2} |x(t)|^2\,dtP∞​=ΔT→∞lim​T1​∫−T/2T/2​∣x(t)∣2dt
(23)

De forma equivalente:

P∞=Δlim⁡T→∞12T∫−TT∣x(t)∣2 dtP_\infty \overset{\Delta}{=} \lim_{T\to\infty} \frac{1}{2T} \int_{-T}^{T} |x(t)|^2\,dtP∞​=ΔT→∞lim​2T1​∫−TT​∣x(t)∣2dt
(24)
Señales discretas
P∞=Δlim⁡N→∞12N+1∑n=−NN∣x[n]∣2P_\infty \overset{\Delta}{=} \lim_{N\to\infty} \frac{1}{2N+1} \sum_{n=-N}^{N} |x[n]|^2P∞​=ΔN→∞lim​2N+11​n=−N∑N​∣x[n]∣2
(25)

Potencia media para señales periódicas¶

Si la señal es periódica, la potencia media puede calcularse sobre un único periodo.

Señales continuas

Para una señal continua periódica de periodo TTT:

P∞=Δ1T∫⟨T⟩∣x(t)∣2 dtP_\infty \overset{\Delta}{=} \frac{1}{T} \int_{\langle T\rangle} |x(t)|^2\,dtP∞​=ΔT1​∫⟨T⟩​∣x(t)∣2dt
(26)
Señales discretas

Para una señal discreta periódica de periodo NNN:

P∞=Δ1N∑n∈⟨N⟩∣x[n]∣2P_\infty \overset{\Delta}{=} \frac{1}{N} \sum_{n\in\langle N\rangle} |x[n]|^2P∞​=ΔN1​n∈⟨N⟩∑​∣x[n]∣2
(27)

Ejemplo: x(t)=2.x(t)=2.x(t)=2.

Pi(t)=∣x(t)∣2=4.P_i(t)=|x(t)|^2=4.Pi​(t)=∣x(t)∣2=4.
(28)
E∞=∫−∞∞∣x(t)∣2dt=∫−∞∞4dt=∞.E_\infty=\int_{-\infty}^\infty |x(t)|^2 dt=\int_{-\infty}^\infty 4 dt=\infty.E∞​=∫−∞∞​∣x(t)∣2dt=∫−∞∞​4dt=∞.
(29)
P∞=lim⁡T→∞1T∫−T/2T/2Pi(t)dt=lim⁡T→∞4TT=4.P_\infty=\lim_{T\to\infty}\frac{1}{T}\int_{-T/2}^{T/2} P_i(t) dt=\lim_{T\to\infty}\frac{4T}{T}=4.P∞​=T→∞lim​T1​∫−T/2T/2​Pi​(t)dt=T→∞lim​T4T​=4.
(30)

Señales de energía y de potencia¶

Señales de energía

0<E∞<∞.0<E_\infty<\infty.0<E∞​<∞.

import sys

# ==============================================================================
# 1. EJE TEMPORAL
# ==============================================================================

t_min, t_max = -5.0, 5.0
num_points = 3000
t = np.linspace(t_min, t_max, num_points)

initial_signal = "Senoidal"
A0 = 1.0
T0 = 2.0

# ==============================================================================
# 2. FUNCIÓN AUXILIAR
# ==============================================================================

def compute_signal(name, A, T):

    if name == "Senoidal":
        x = A*np.sin(2*np.pi*t/T)

    elif name == "Cosenoidal con offset":
        x = 0.5*A + A*np.cos(2*np.pi*t/T)

    elif name == "Pulso rectangular":
        x = A*((t >= -T/2) & (t <= T/2)).astype(float)

    elif name == "Exponencial decreciente":
        x = A*np.exp(-t)*(t >= 0)

    elif name == "Gaussiana":
        x = A*np.exp(-t**2)

    elif name == "Señal cuadrada periódica":
        x = A*np.sign(np.sin(2*np.pi*t/T))

    return x

# ==============================================================================
# 3. ESTADO INICIAL
# ==============================================================================

x0 = compute_signal(initial_signal, A0, T0)

p_inst0 = x0**2

mean0 = np.trapezoid(x0, t)/(t_max - t_min)

energy0 = np.trapezoid(p_inst0, t)

peak0 = np.max(np.abs(x0))

if initial_signal == "Senoidal":
    power0 = A0**2/2

elif initial_signal == "Cosenoidal con offset":
    power0 = A0**2/4 + A0**2/2

elif initial_signal == "Señal cuadrada periódica":
    power0 = A0**2

else:
    power0 = 0

source = ColumnDataSource(data=dict(
    t=t,
    x=x0,
    p_inst=p_inst0,
    mean=np.full_like(t, mean0),
    peak_pos=np.full_like(t, peak0),
    p_mean=np.full_like(t, power0),
))

callback = CustomJS(
    args=dict(
        source=source,
        select=select,
        amp_slider=amp_slider,
        period_slider=period_slider,
        info=info,
        t_min=t_min,
        t_max=t_max
    ),
    code="""

    const data = source.data;
    const t = data["t"];

    const name = select.value;

    const A = amp_slider.value;
    const T = period_slider.value;

    const x = [];
    const p_inst = [];

    for (let i = 0; i < t.length; i++) {

        const ti = t[i];

        let value = 0;

        // ==========================================================
        // DEFINICIÓN DE LA SEÑAL
        // ==========================================================

        if (name === "Senoidal") {

            value = A*Math.sin(2*Math.PI*ti/T);

        }

        else if (name === "Cosenoidal con offset") {

            value = 0.5*A + A*Math.cos(2*Math.PI*ti/T);

        }

        else if (name === "Pulso rectangular") {

            value = (ti >= -T/2 && ti <= T/2) ? A : 0;

        }

        else if (name === "Exponencial decreciente") {

            value = (ti >= 0) ? A*Math.exp(-ti) : 0;

        }

        else if (name === "Gaussiana") {

            value = A*Math.exp(-ti*ti);

        }

        else if (name === "Señal cuadrada periódica") {

            value = A*Math.sign(Math.sin(2*Math.PI*ti/T));

        }

        x.push(value);

        p_inst.push(value*value);
    }

    // ==============================================================
    // VALOR MEDIO Y ENERGÍA (TRAPECIOS)
    // ==============================================================

    let integral_x = 0;
    let energy = 0;

    for (let i = 0; i < t.length - 1; i++) {

        const dt = t[i+1] - t[i];

        integral_x += 0.5*(x[i] + x[i+1])*dt;

        energy += 0.5*(p_inst[i] + p_inst[i+1])*dt;
    }

    const duration = t_max - t_min;

    const mean = integral_x/duration;

    // ==============================================================
    // POTENCIA MEDIA TOTAL
    // ==============================================================

    let power_mean_total = 0;

    if (name === "Senoidal") {

        power_mean_total = A*A/2;

    }

    else if (name === "Cosenoidal con offset") {

        power_mean_total = A*A/4 + A*A/2;

    }

    else if (name === "Señal cuadrada periódica") {

        power_mean_total = A*A;

    }

    else {

        power_mean_total = 0;
    }

    // ==============================================================
    // VALOR DE PICO
    // ==============================================================

    let peak = 0;

    for (let i = 0; i < x.length; i++) {

        peak = Math.max(peak, Math.abs(x[i]));
    }

    // ==============================================================
    // CLASIFICACIÓN
    // ==============================================================

    let classification = "";

    if (
        name === "Senoidal" ||
        name === "Cosenoidal con offset" ||
        name === "Señal cuadrada periódica"
    ) {

        classification =
        "Es una señal de potencia: su energía total tiende a infinito, pero su potencia media es finita.";
    }

    else {

        classification =
        "Es una señal de energía: su energía total es finita y su potencia media total tiende a cero.";
    }

    // ==============================================================
    // ACTUALIZAR DATOS
    // ==============================================================

    data["x"] = x;

    data["p_inst"] = p_inst;

    data["mean"] = Array(t.length).fill(mean);

    data["peak_pos"] = Array(t.length).fill(peak);

    data["p_mean"] = Array(t.length).fill(power_mean_total);

    // ==============================================================
    // ACTUALIZAR TEXTO
    // ==============================================================

    info.text = `
    <b>Parámetros calculados</b><br>
    Valor medio en el intervalo mostrado: ${mean.toFixed(3)}<br>
    Valor de pico: ${peak.toFixed(3)}<br>
    Energía en el intervalo mostrado: ${energy.toFixed(3)}<br>
    Potencia media total: ${power_mean_total.toFixed(3)}<br><br>
    ${classification}
    `;

    source.change.emit();

"""
)
